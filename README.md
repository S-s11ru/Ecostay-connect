# EcoStay Connect

EcoStay Connect is a full-stack homestay and eco-tourism web application that helps users discover eco-friendly stays and promotes sustainable tourism through a modern and responsive platform.

## GitHub Repository

https://github.com/S-s11ru/Ecostay-connect

## Features

* User registration and login
* Browse eco-friendly homestays
* View property details
* Responsive user interface
* AI-assisted feature integration
* Secure backend APIs

## Tech Stack

### Frontend

* React.js
* HTML
* CSS
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* MongoDB
