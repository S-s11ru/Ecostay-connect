# EcoStay Connect

## Week 5 – Database Design & Management

### Database

MongoDB Atlas with Mongoose ODM

### Features

* Create homestay listings
* View all homestays
* View a single homestay
* Update homestay information
* Delete homestay listings
* Booking management

### API Endpoints

* GET /api/stays
* GET /api/stays/:id
* POST /api/stays
* PUT /api/stays/:id
* DELETE /api/stays/:id

### Environment Variables

Create a .env file with:
MONGO_URI
PORT
JWT_SECRET

### Database Schema

Collections:

* Users
* Homestays
* Bookings
